# DS312 Final Project: WESM Electricity Market Analysis

## Data Mining and Application | 1st Semester A.Y. 2026–2027

### Project Overview

This project analyzes Philippine Wholesale Electricity Spot Market (WESM) data to identify electricity market patterns, investigate price movements and potential price spikes, and generate insights that may support market analysis and decision-making.

The project follows the complete data mining process:

**Business Problem → Data → Preprocessing → Exploration → Modeling → Interpretation → Communication**

## Repository Structure

### `data/`
Contains the datasets used in the project.

- `raw/` – Original datasets that remain unchanged.
- `interim/` – Temporary or partially processed datasets.
- `processed/` – Final cleaned datasets used for analysis and modeling.

### `notebooks/`
Contains the Jupyter notebooks for each project phase.

- `phase_1/` – Dataset selection and business problem.
- `phase_2/` – Data preprocessing.
- `phase_3/` – Exploratory data analysis.
- `phase_4/` – Data mining and machine learning.
- `final/` – Master notebook containing the complete project.

### `src/`
Contains reusable Python code for data loading, preprocessing, analysis, modeling, and other utility functions.

### `results/`
Contains tables and outputs generated during preprocessing, EDA, and modeling.

### `visuals/`
Contains exported charts and figures used for analysis, the final report, poster, and presentation.

### `reports/`
Contains group submissions, individual narrative reports, and final project documentation.

### `presentation/`
Contains the final project poster and PowerPoint presentation.

### `docs/`
Contains supporting project documentation, including the data dictionary and methodology.

## Data Mining Techniques

The project will explore appropriate data mining techniques based on the business problem and available data. These may include clustering, classification, association rule mining, and cost or impact analysis.

## Reproducibility

Raw data files are preserved separately from processed datasets. All preprocessing, analysis, and modeling decisions are documented in the project notebooks to support reproducibility.
